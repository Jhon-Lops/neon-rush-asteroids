# Neon Rush Asteroids

Neon Rush Asteroids is a classic arcade experience reinvented with neon visuals. Pilot your spaceship, destroy asteroids, and survive for as long as possible as their numbers increase over time.

## How to Play

### PC

- **Move:** Use **WASD** or the **Arrow Keys**.
- **Shoot:** Press **Spacebar**.

### Mobile

- **Move:** Use the virtual joystick on the left side of the screen.
- **Shoot:** Tap the virtual **FIRE** button on the right side.

Destroy asteroids and survive for as long as possible.

## Available Languages

Portuguese (PT), English (EN), French (FR), Italian (IT), Spanish (ES), Russian (RU), and Chinese (ZH).

## Godot Project

This project was created with Godot 4.7 and includes a Web export in the `html` folder.
